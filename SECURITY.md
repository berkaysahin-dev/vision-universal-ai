# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Vision Universal AI team takes security very seriously. If you discover a security vulnerability, please DO NOT open a public GitHub issue.

Instead, please report security issues privately via email to:
**security@vision-ai.dev**

We will acknowledge receipt within 24 hours and provide a timeline for triage and remediation.
